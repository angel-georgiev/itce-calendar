# ITCE Training Calendar

A static, filterable and sortable view of the upcoming public trainings on [itce.com/training-schedule](https://www.itce.com/training-schedule/), published with GitHub Pages:
**https://angel-georgiev.github.io/itce-calendar/**

## How it works

| File | Role |
|---|---|
| `index.html`, `assets/` | The page. It loads `data/sessions.json` in the browser. There is no build step. |
| `data/sessions.json` | Generated by `scripts/sync.py`. Do not edit it by hand. |
| `data/last-sync.md` | The report from the last sync: added, removed and changed sessions, sessions without a course page, and website data issues. |
| `scripts/sync.py` | Scrapes the website's schedule and course pages. Uses only the Python standard library. |

Everything on the page comes from itce.com and nothing else: sessions, dates, language, format, learning method, description, link and price, plus category, "Who should attend" and what the price includes, taken from each course page. Fields a course page doesn't have stay empty. The script reads both the English and the Bulgarian schedule. A course link is kept only if it opens that course's own page. The page hides sessions whose start date has passed.

## Updating

```sh
python3 scripts/sync.py          # refresh data/sessions.json and data/last-sync.md
git diff --stat data/            # review, then commit and push to main
```

GitHub Pages serves `main` / root, so the site updates about a minute after a push.
