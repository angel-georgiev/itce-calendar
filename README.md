# ITCE Training Calendar

A static, filterable and sortable view of the upcoming public trainings on [itce.com/training-schedule](https://www.itce.com/training-schedule/), published with GitHub Pages:
**https://angel-georgiev.github.io/itce-calendar/**

## How it works

| File | Role |
|---|---|
| `index.html`, `assets/` | The page. It loads `data/sessions.json` in the browser. There is no build step. |
| `data/sessions.json` | Generated by `scripts/sync.py`. Do not edit it by hand. |
| `data/enrichment.json` | Fields the website doesn't publish: instructor per session (`CODE\|YYYY-MM-DD`), plus category, certification exam, target role and fallback course link per course code. Edit this file by hand. |
| `data/last-sync.md` | The report from the last sync: added, removed and changed sessions, and missing instructors, categories or links. |
| `scripts/sync.py` | Scrapes the website and merges it with `enrichment.json`. Uses only the Python standard library. |
| `scripts/import_xlsx.py` | One-time import of the original Excel schedule into `enrichment.json`. |

The website is the source of truth for sessions, dates, language, format, learning method, description, link and price. The page hides sessions whose start date has passed.

## Updating

```sh
python3 scripts/sync.py          # refresh data/sessions.json and data/last-sync.md
git diff --stat data/            # review, then commit and push to main
```

GitHub Pages serves `main` / root, so the site updates about a minute after a push.

To set an instructor for a new session, add `"CODE|YYYY-MM-DD": "Name"` under `instructors` in `data/enrichment.json`, then run the sync again.
